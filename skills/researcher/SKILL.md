---

启动一个 **background agent** 执行研究，这样你可以继续工作，它在后台阅读。

它的任务：

1. 针对 **primary sources**（一手资料）研究问题 — 官方文档、源代码、规范、第一方 API — 不是二手转述。每个结论追溯到它所属的原始来源。
2. 将结论写入单个 Markdown 文件，每条结论标注来源。
3. 存放在仓库已有的笔记目录；遵循现有惯例，如果没有惯例，放在合理位置并说明位置。
