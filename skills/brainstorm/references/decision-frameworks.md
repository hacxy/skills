# 决策框架参考

## 1. 决策矩阵（Decision Matrix）

### 适用场景

- 多个方案对比
- 需要量化评估
- 涉及多个维度

### 使用方法

1. 列出所有备选方案
2. 确定评估维度（成本、收益、风险等）
3. 为每个维度分配权重（1-10分）
4. 对每个方案在每个维度上打分（1-10分）
5. 计算加权总分
6. 选择得分最高的方案

### 示例

| 维度 | 权重 | 方案A | 方案B | 方案C |
| ------ | ------ | ------- | ------- | ------- |
| 成本 | 8 | 7 | 5 | 6 |
| 收益 | 9 | 6 | 8 | 7 |
| 风险 | 7 | 5 | 6 | 8 |
| 时间 | 6 | 8 | 4 | 5 |
| **加权总分** | | **6.1** | **6.0** | **6.5** |

## 2. SWOT 分析

### 适用场景

- 评估方案的优劣势
- 分析外部机会和威胁
- 战略规划

### 使用方法

1. **Strengths（优势）**：方案的内在优势
2. **Weaknesses（劣势）**：方案的内在劣势
3. **Opportunities（机会）**：外部环境带来的机会
4. **Threats（威胁）**：外部环境带来的威胁

### 示例

```
方案：从 Java 转 Go

优势：
- Go 语言简洁，学习曲线平缓
- 并发性能好，适合云原生开发
- 薪资水平相对较高

劣势：
- 生态系统相对较小
- 现有 Java 经验可能浪费
- 需要重新建立技术栈

机会：
- 云原生和微服务趋势
- 更多公司采用 Go
- 技术转型窗口期

威胁：
- Go 岗位数量相对较少
- 技术变化快，可能被新语言取代
- 经济下行期招聘需求减少
```

## 3. 六顶思考帽（Six Thinking Hats）

### 适用场景

- 全面思考问题
- 避免思维偏见
- 团队决策

### 使用方法

1. **白帽**：客观事实和数据
2. **红帽**：直觉和情感
3. **黑帽**：风险和问题
4. **黄帽**：优势和机会
5. **绿帽**：创新和替代方案
6. **蓝帽**：控制和总结

### 示例

```
问题：是否要创业？

白帽（事实）：
- 当前存款 50 万
- 家庭月支出 2 万
- 行业平均创业成功率 10%

红帽（情感）：
- 对现状感到厌倦
- 渴望自主和成就感
- 担心失败后的社会压力

黑帽（风险）：
- 可能损失全部积蓄
- 影响家庭生活质量
- 创业失败后就业困难

黄帽（机会）：
- 实现财务自由的可能
- 做自己热爱的事业
- 积累宝贵经验

绿帽（创新）：
- 先兼职创业，降低风险
- 找合伙人分担风险
- 选择轻资产模式

蓝帽（控制）：
- 需要更多信息
- 设定决策时间线
- 制定风险应对计划
```

## 4. 决策树（Decision Tree）

### 适用场景

- 涉及不确定性的决策
- 需要评估概率和期望值
- 多阶段决策

### 使用方法

1. 画出决策树结构
2. 为每个节点分配概率
3. 为每个结果分配价值
4. 计算期望值
5. 选择期望值最高的路径

### 示例

```
决策：是否跳槽到创业公司？

当前工作：
- 稳定薪资：100%
- 涨薪幅度：10%/年
- 满意度：60%

创业公司：
- 高薪：70% 概率
  - 薪资涨幅：50%
  - 满意度：80%
- 失败：30% 概率
  - 失业：3-6个月
  - 重新找工作
  - 满意度：40%

期望值计算：
当前工作：0.6 × 100 = 60
创业公司：0.7 × 80 + 0.3 × 40 = 68
```

## 5. 10/10/10 法则

### 适用场景

- 避免短期情绪影响
- 考虑长期后果
- 快速决策

### 使用方法

问自己三个问题：

1. **10分钟后**：我会怎么看待这个决定？
2. **10个月后**：我会怎么看待这个决定？
3. **10年后**：我会怎么看待这个决定？

### 示例

```
问题：是否接受这个高薪但加班多的工作？

10分钟后：
- 可能会因为高薪而兴奋
- 可能会担心加班影响生活

10个月后：
- 可能已经适应工作节奏
- 可能因为加班而疲惫
- 可能因为收入增加而改善生活

10年后：
- 可能因为这段经历而职业提升
- 可能因为健康问题而后悔
- 可能因为错过家庭时光而遗憾
```

## 6. 逆向思维（Inversion）

### 适用场景

- 避免重大错误
- 识别潜在风险
- 简化复杂问题

### 使用方法

1. 明确目标
2. 问自己："什么会导致完全相反的结果？"
3. 避免这些因素

### 示例

```
目标：成功创业

逆向思考：什么会导致创业失败？
- 没有市场需求
- 现金流断裂
- 团队不和谐
- 产品没有竞争力
- 营销策略错误

避免这些因素：
- 先验证市场需求
- 控制成本，确保现金流
- 仔细选择合伙人
- 打造差异化产品
- 学习营销知识
```

## 7. 价值排序（Value Sorting）

### 适用场景

- 明确个人价值观
- 做符合内心的决定
- 解决价值观冲突

### 使用方法

1. 列出所有重要价值（金钱、时间、健康、家庭、成就感等）
2. 按重要性排序
3. 评估每个方案是否符合你的价值排序

### 示例

```
价值排序：
1. 健康
2. 家庭
3. 成就感
4. 金钱
5. 社会地位

方案评估：
方案A（高薪但加班多）：符合金钱，但违背健康和家庭
方案B（稳定但收入一般）：符合健康和家庭，但缺乏成就感
方案C（创业）：可能实现成就感，但风险健康和家庭
```

## 8. 决策平衡单（Decision Balance Sheet）

### 适用场景

- 个人重大决定
- 需要全面考虑利弊
- 涉及情感因素

### 使用方法

1. 画一个四格表格
2. 左边：个人 gains/losses
3. 右边：他人 gains/losses
4. 上面：pros（好处）
5. 下面：cons（坏处）

### 示例

```
决定：是否移民

个人好处：
- 更好的生活环境
- 子女教育机会
- 职业发展空间

个人坏处：
- 文化适应困难
- 远离亲友
- 重新开始

他人好处：
- 家人可能受益
- 子女未来发展

他人坏处：
- 父母需要照顾
- 配偶可能不适应
```

## 使用建议

1. **不要依赖单一框架**：不同框架适合不同场景
2. **结合使用**：可以用多个框架分析同一个问题
3. **关注框架的局限性**：任何框架都有适用范围
4. **最终靠自己**：框架只是工具，决定权在你
5. **接受不确定性**：没有完美的决定，只有最适合当下的决定
